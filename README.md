# Sortable List (Test Task)

A drag-and-drop game where blocks must be arranged into a given target order.  
Supports both dragging and click-to-swap, and works correctly on desktop and mobile.  
Shows success/error feedback and lets you restart the game.

[**Live Demo →**](https://deemoor.github.io/test-task-sortable-list/)

## Tech Stack
React · TypeScript · Vite  
React Draggable · Sass Modules

## Getting Started
```bash
npm install
npm run dev      # http://localhost:5173
```
